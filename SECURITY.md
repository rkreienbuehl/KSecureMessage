# Security policy

KSecureMessage is pre-1.0 and has **not** had an independent security audit.
See [docs/security-review.md](docs/security-review.md) for the threat model
and the review checklist.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private
vulnerability reporting for
[rkreienbuehl/KSecureMessage](https://github.com/rkreienbuehl/KSecureMessage/security/advisories/new),
not in a public issue.

## Supported versions

Only the latest 0.x release receives fixes.
